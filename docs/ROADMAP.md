# Stychat roadmap

## Classic Social Edition (current)

- Light and dark appearance settings
- Editable profile and profile cards
- One-to-one messaging
- Group creation and realtime text messages
- Persistent SQLite history

## Next milestones

1. Upload profile photos and group icons with strict file-size/type validation.
2. Group management: invite/remove members, rename group, leave group, owner/admin roles.
3. Delivery/read states and unread counters for group chats.
4. File and image attachments with safe storage and access checks.
5. Notification preferences and browser notifications.
6. Production hardening: rate limits, secure session storage, HTTPS deployment, logging, backups, and security review.
7. Optional voice/video calling after the core messaging experience is stable.


## Completed in 1.0.6
- Per-conversation draft persistence in the current session.
- Search within loaded group messages by sender name or message text.
