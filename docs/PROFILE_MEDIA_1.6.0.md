# Stychat 1.6.0: профили и мультимедиа

- Добавлен отдельный раздел «Мой профиль» в настройках: отображаемое имя, статус и выбор аватара-эмодзи.
- Выбранный аватар сохраняется в SQLite и синхронизируется через событие `profile:updated`.
- Добавлена загрузка изображений, видео, аудио и PDF до 8 МБ в личные и групповые чаты.
- Файлы хранятся в `apps/api/data/uploads` (папка создаётся автоматически при запуске API); в истории сообщений хранится ссылка и метаданные.
- Старые базы мигрируют автоматически, поле аватара по умолчанию `🙂`.

Поддерживаемые типы: JPEG, PNG, GIF, WebP, MP4, WebM, MP3, OGG, WAV и PDF.
