# Stychat 1.5.0 design refresh

## Intent
Give Stychat by Win Stydio a consistent visual identity rather than imitating another messenger. The direction uses emerald accents, layered neutral surfaces, clear selected states, and calm interaction feedback.

## Updated areas
- Navigation rail and brand mark
- Sidebar header, self card, search, filters, contact rows, and connection footer
- Conversation header, message history, bubbles, and composer
- Welcome screen, authentication card, and modal surfaces
- Light and dark theme variables

## Accessibility and responsive behavior
- Visible focus rings for keyboard navigation
- Reduced-motion preference support
- Layout refinements for tablet and mobile widths

## Scope
This release is primarily a visual refresh. Existing API behavior and app flows are retained. It does not add file uploads, calls, end-to-end encryption, or other features not already implemented.
